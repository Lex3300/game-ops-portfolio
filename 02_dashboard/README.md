# 模块② · 数据看板

[← 返回作品集首页](../README.md)

六个区块：KPI 诊断（区块01）· 付费结构（区块02）· 活动排期甘特（区块03）· 配置工作台（区块04）· 客服 AI 自动回复（区块05）· 舆情监控（区块06）。

## 两种打开方式

| 方式 | 操作 | 说明 |
|---|---|---|
| 本地完整版 | 双击根目录 `dashboard.bat` | 先跑活动引擎重建数据，再启动 `http://127.0.0.1:8765`；区块04 的写盘按钮**真实可用**（Excel → SQL → git 命令） |
| 单文件版 | 双击根目录 `index.html` | ECharts 与数据全部内联，`file://` 双击即看；区块04 进入静态快照模式，回放最近一次真实发布记录，页面顶部说明条会标明当前模式 |

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 看板页面结构（源码版，引用下方资源） |
| `build_data.py` | 从 `data/game.db` + 各模块产物生成 `data.js` |
| `build_single.py` | 把 echarts/data/rag 全部内联，打包成根目录单文件 `index.html` |
| `serve.py` | 本地桥 API：状态探测 / 写 Excel / 打开目录 / 发布配置 / 生成 git 命令 |
| `rag.js` | 客服检索内核（BM25 + 同义词归一），区块05 使用，配 `05_cs_rag/test_rag.js` 回归 |
| `data.js` | 看板数据快照（构建产物） |
