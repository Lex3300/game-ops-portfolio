## 三、维护方式

1. **加活动**：在 `arsenal_seed.json` 里加一条（指定 `activity_id` 与 `type`），重跑引擎 → 自动建表 `cfg_act_xxx`、写主数据、回填 `config_table`。
2. **改配置**：改该活动种子里的 `config` 后重跑引擎（种子是配置的唯一真源，会覆盖表内值）；临时试算也可直接 `UPDATE cfg_act_xxx SET ...`。
3. **改字段**：在引擎 `CONFIG_TEMPLATES` 里给该类型加列，重跑会自动 `ALTER TABLE` 补齐。
4. **删活动**：种子中移除后重跑，引擎不会自动删表（避免误删历史），需手工 `DROP TABLE`。
