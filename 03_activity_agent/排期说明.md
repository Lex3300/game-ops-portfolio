1. **已定档不动**：`start_date <= 今天` 的排期自动锁定，引擎不会修改其日期、规则与备注；只有未上线的活动允许调整或删除重排，本引擎当前只做「新增」和「调整」，不删除。

3. 其余活动（留存 / 活跃 / 回流 / 消耗杠杆）缺少可外推的对照基线，**不做数字估计**，宁缺勿编；需要评估时应做 A/B 或对照期。
4. 结构缺口占日均缺口 ≥ 10% 时，判定「付费活动相关」为主导，才排大 R 冲刺活动；否则优先修留存与转化。
