# 运行说明

面向想在本机跑通整个项目的人。看板在线预览、单文件查看不需要本节内容。

## 环境要求

- Windows 10/11（`.bat` 脚本会自动定位 Python 解释器，不要求把 Python 加入 PATH）
- 无需联网；所有数据本地生成

## 三个一键脚本

| 脚本 | 作用 |
|---|---|
| `start.bat` | 生成 / 增量追加模拟数据（首次补齐全量历史，之后只追加缺失天数；已生成的日期不会被改写） |
| `dashboard.bat` | 跑活动引擎 → 生成舆情语料 → 重建看板数据 → 启动本地服务并打开 `http://127.0.0.1:8765`（区块04 的写盘按钮依赖这个服务） |
| `export.bat` | 把数据库导出到 `data/export/`（8 表 Excel + 全量 CSV，UTF-8 带 BOM，Excel 打开不乱码），并自动用 Excel 打开结果 |

命令行用法（PowerShell，必须先切到项目目录）：

```powershell
cd "$HOME\Desktop\作品集"     # 脚本按相对路径找 data/game.db
.\start.bat                   # 增量生成（已是最新则自动跳过）
.\start.bat --days 90         # 指定生成天数
.\export.bat --list           # 看看能导出哪些数据源
.\export.bat --csv-only       # 只要 CSV
```

## 重新打包单文件看板

改了 `02_dashboard/index.html` 或重建 `data.js` 后，重新生成根目录 `index.html`：

```powershell
cd "02_dashboard"

```

## 直接查数据库

`data/game.db` 用任意 SQLite 客户端打开即可（DB Browser for SQLite / Navicat / DBeaver）。推荐查**视图**（派生指标已算好）：

| 视图 / 表 | 内容 |
|---|---|
| `v_daily_kpi` | 日粒度大盘：新增 / 非新增活跃 / DAU / 付费率 / 付费用户 / 流水 / ARPU / ARPPU |
| `v_tier_daily` | 各付费档位：用户数 / 人数占比 / 人均付费 / 流水 / 流水占比 |
| `v_retention_wide` | 每个新增队列的 D1~D30 留存率 |
| `retention_cohorts` | 留存长表（队列日期 × 天数），宽表由它派生 |
| `v_threshold_daily` | 新增阈值：每日流失用户数 / 新增阈值 / 安全边际 / 流失率 / 涨跌状态与连续天数 |
| `v_consistency` | 一致性巡检——查出任何一行都说明数据有问题，正常应为 0 行 |

## 常见问题

**提示 `python` 不是内部或外部命令？**
不要直接敲 `python xxx.py`。统一用上面的 `.bat` 脚本，它们会自己定位解释器；
确实需要手动调解释器时用完整路径：
`& "$HOME\.workbuddy\binaries\python\envs\default\Scripts\python.exe" 脚本.py`

**CSV 里的比率为什么是小数？**
CSV 存原始值（如 `0.083524`），导出的 Excel 里已设成百分比显示（`8.35%`）。

**看板打开后区块04 按钮是灰的？**
那是静态快照模式（回放最近一次真实发布记录）。要启用真实写盘，双击 `dashboard.bat` 启动本地服务。
